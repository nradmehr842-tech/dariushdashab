# بازی حکم آنلاین داریوش

این پوشه برای اجرای مستقیم بازی روی Render آماده شده است.

## روش راه‌اندازی

1. همه فایل‌های این پوشه را داخل یک مخزن جدید GitHub قرار دهید.
2. در Render گزینه **New > Web Service** را بزنید و مخزن را انتخاب کنید.
3. تنظیمات را به شکل زیر قرار دهید:
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
4. در بخش Environment دو متغیر بسازید:
   - `ADMIN_PIN`: رمز چهار رقمی داریوش، برای نمونه `2006`
   - `ADMIN_SECRET`: یک متن طولانی و تصادفی
5. روی **Create Web Service** بزنید. پس از انتشار، لینک Render را برای دوستان بفرستید.

## نکته ذخیره بازی

وضعیت بازی بین همه بازیکنان آنلاین مشترک است. در سرویس رایگان Render، خاموش‌شدن یا راه‌اندازی مجدد سرور می‌تواند بازی ذخیره‌شده را پاک کند؛ برای یک دورهمی آنلاین مشکلی ایجاد نمی‌کند و بازی بعدی از نو شروع می‌شود. برای نگهداری دائمی، می‌توانید در پلن‌های دارای Persistent Disk مسیر فایل داده را با متغیر `DATA_FILE` روی دیسک دائمی قرار دهید.
